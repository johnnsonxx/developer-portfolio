PRODUCTION INCIDENT · ROOT CAUSE ANALYSIS

Database Lock：從大量交易阻塞，
找到真正的系統性根因。

01症狀

交易持續等待，後續請求陸續阻塞

02根因

外部 API 無 timeout，DB transaction 長時間持鎖

03處理

重定交易邊界，加入 timeout 與補償流程

External I/O 不應在持有 Database Lock 時執行。DB Transaction 不等於整個 Payment Process 的 Transaction。
